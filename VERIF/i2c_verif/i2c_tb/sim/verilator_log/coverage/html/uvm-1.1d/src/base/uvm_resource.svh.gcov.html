     608             : // Class: uvm_resource_pool
     609             : //
     610             : // The global (singleton) resource database.
     611             : //
     612             : // Each resource is stored both by primary name and by type handle.  The
     613             : // resource pool contains two associative arrays, one with name as the
     614             : // key and one with the type handle as the key.  Each associative array
     615             : // contains a queue of resources.  Each resource has a regular
     616             : // expression that represents the set of scopes over with it is visible.
     617             : //
     618             : //|  +------+------------+                          +------------+------+
     619             : //|  | name | rsrc queue |                          | rsrc queue | type |
     620             : //|  +------+------------+                          +------------+------+
     621             : //|  |      |            |                          |            |      |
     622             : //|  +------+------------+                  +-+-+   +------------+------+
     623             : //|  |      |            |                  | | |<--+---*        |  T   |
     624             : //|  +------+------------+   +-+-+          +-+-+   +------------+------+
     625             : //|  |  A   |        *---+-->| | |           |      |            |      |
     626             : //|  +------+------------+   +-+-+           |      +------------+------+
     627             : //|  |      |            |      |            |      |            |      |
     628             : //|  +------+------------+      +-------+  +-+      +------------+------+
     629             : //|  |      |            |              |  |        |            |      |
     630             : //|  +------+------------+              |  |        +------------+------+
     631             : //|  |      |            |              V  V        |            |      |
     632             : //|  +------+------------+            +------+      +------------+------+
     633             : //|  |      |            |            | rsrc |      |            |      |
     634             : //|  +------+------------+            +------+      +------------+------+

     636             : // The above diagrams illustrates how a resource whose name is A and
     637             : // type is T is stored in the pool.  The pool contains an entry in the
     638             : // type map for type T and an entry in the name map for name A.  The
     639             : // queues in each of the arrays each contain an entry for the resource A
     640             : // whose type is T.  The name map can contain in its queue other
     641             : // resources whose name is A which may or may not have the same type as
     642             : // our resource A.  Similarly, the type map can contain in its queue
     643             : // other resources whose type is T and whose name may or may not be A.
     644             : //

     646             : // from the pool by calling <get_by_name> or <get_by_type>.  When an object 
     647             : // creates a new resource and calls <set> the resource is made available to be
     648             : // retrieved by other objects outside of itsef; an object gets a
     649             : // resource when it wants to access a resource not currently available
     650             : // in its scope.
     651             : //

     653             : // whether you get by name or by type the resource's visibility is
     654             : // the same.

     657             : // record of each get, whether by <get_by_type> or <get_by_name>, is stored

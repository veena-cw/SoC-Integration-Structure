      26             : //
      27             : //------------------------------------------------------------------------------
      28             : // Base class for all task phases.
      29             : // It forks a call to <uvm_phase::exec_task()>
      30             : // for each component in the hierarchy.
      31             : //
      32             : // The completion of the task does not imply, nor is it required for, 
      33             : // the end of phase. Once the phase completes, any remaining forked 
      34             : // <uvm_phase::exec_task()> threads are forcibly and immediately killed.
      35             : //
      36             : // By default, the way for a task phase to extend over time is if there is
      37             : // at least one component that raises an objection.  
      38             : //| class my_comp extends uvm_component;
      39             : //|    task main_phase(uvm_phase phase);
      40             : //|       phase.raise_objection(this, "Applying stimulus")
      41             : //|       ...
      42             : //|       phase.drop_objection(this, "Applied enough stimulus")
      43             : //|    endtask
      44             : //| endclass
      45             : // 
      46             : //   
      47             : // There is however one scenario wherein time advances within a task-based phase
      48             : // without any objections to the phase being raised. If two (or more) phases 
      49             : // share a common successor, such as the <uvm_run_phase> and the 
      50             : // <uvm_post_shutdown_phase> sharing the <uvm_extract_phase> as a successor, 
      51             : // then phase advancement is delayed until all predecessors of the common 
      52             : // successor are ready to proceed.  Because of this, it is possible for time to 
      53             : // advance between <uvm_component::phase_started> and <uvm_component::phase_ended>
      54             : // of a task phase without any participants in the phase raising an objection.

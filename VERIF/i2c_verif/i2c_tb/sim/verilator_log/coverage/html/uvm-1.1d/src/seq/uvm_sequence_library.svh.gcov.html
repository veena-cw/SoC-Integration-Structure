      30             : // The ~uvm_sequence_library~ is a sequence that contains a list of registered

      33             : // user-defined mode.
      34             : //
      35             : // When started (as any other sequence), the sequence library will randomly
      36             : // select and execute a sequence from its ~sequences~ queue. If in
      37             : // <UVM_SEQ_LIB_RAND> mode, its <select_rand> property is randomized and used
      38             : // as an index into ~sequences~.  When in <UVM_SEQ_LIB_RANC> mode, the
      39             : // <select_randc> property is used. When in <UVM_SEQ_LIB_ITEM> mode, only
      40             : // sequence items of the ~REQ~ type are generated and executed--no sequences

      42             : // <select_sequence> method is called to obtain the index for selecting the

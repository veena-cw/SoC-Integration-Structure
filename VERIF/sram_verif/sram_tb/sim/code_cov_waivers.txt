# code_cov_waivers.txt -- RTL code-coverage waivers (make code_cov)
#
# Points listed here stay in the coverage database but are reported
# as WAIVED and left out of the percentages. Only points that no
# legal stimulus can reach with sram_top's configuration belong here.
#
# Format (one waiver per line):
#   <file>:<line>  <type>  [@<instance substring>]  ["<point text>"]  <reason>
#     type        = line | branch | expr | toggle | *   (* = every type)
#     point text  = substring of the point's description (expression
#                   term, branch if/else, toggle signal); limits the
#                   waiver to those points -- a line usually has several
#                   points and only some are unreachable
#
# code_cov_report.py warns about a waiver that matches no point
# (stale line number) and about a waived point that was hit.
# ------------------------------------------------------------
